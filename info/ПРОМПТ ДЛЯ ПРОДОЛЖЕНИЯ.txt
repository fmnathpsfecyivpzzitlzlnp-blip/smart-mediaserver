"Привет! Я продолжаю разработку домашнего медиасервера на Django. Проект уже 'докеризирован' и использует асинхронную обработку видео через Celery и Redis. Вот текущее состояние ключевых файлов и архитектуры.
Цель на сегодня: [ Здесь напишите, что вы хотите сделать. Например: "Реализовать удаление видеофайлов с диска вместе с записью в БД", "Добавить на главную страницу индикаторы статуса для фильмов, которые обрабатываются", "Добавить систему тегов для фильмов" и т.д. ]
Текущая архитектура:
Среда: Проект запускается через docker-compose.
Сервисы: web (Django+Gunicorn), worker (Celery), redis (брокер сообщений), nginx (веб-сервер и прокси).
Воркфлоу обработки видео:
Новые видео кладутся в локальную папку D:\mediaserver\movies_source\.
Команда docker compose exec worker python manage.py scan_movies запускает сканирование.
Сканер создает запись в БД со статусом PENDING и ставит задачу в очередь Celery.
Celery-воркер выполняет задачу: анализирует, конвертирует/перемещает видео в папку media, обновляет статус в БД на READY.
Nginx раздает готовые видеофайлы из папки media после редиректа от Django.
